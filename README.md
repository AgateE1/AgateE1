## Projects

**Start here → [Time to First Purchase](https://github.com/AgateE1/Session-Length-and-Order-Value)**
How long does it take someone to buy, and is that a number worth managing? Median
time-to-purchase held at 19 minutes through a quarter where conversion swung from 3.17% to
near zero - so it predicts nothing, and pushing it down would only shrink baskets. The real
friction is elsewhere: 78% of visitors never reach a product page. Six documented BigQuery
queries, a three-page Looker Studio dashboard, and a full analytical report. Reproducible
against `bigquery-public-data` as written.
